# 控制面实施与交接提示词

本提示词约束实施和完成判定，不记录当前完成状态。先读 `AGENTS.md`、`CLAUDE.md`、
`docs/status/current.md`，以及 `docs/distributed-control-plane.md` 中本任务涉及的完整条款和
§19–§20。当前用户要求优先；不能只挑兼容条款执行，也不能把目标文档当成已部署证据。

请继续完成已经授权的控制面任务，做到正常业务可用、生产实际运行、对应旧实现删除。
不要停在方案、组件、测试、构造器或“已具备接入条件”；更新本提示词后继续实际实现。

## 开始时核对

1. 检查工作区、隔离分支和未提交改动，保护其他任务的工作。读取 issue 的验收要求，对照真实
   UI/CLI 入口、daemon 启动、业务处理、持久状态、客户端调用、部署配置及旧路径，列出具体缺口。
2. 对每项区分“组件已实现”“正常入口已接通”“已部署”“已验收”。缺任何必需环节，整项仍未完成；
   不用“主体完成”“基本完成”“仅待收尾”代替缺口，不提前关闭 issue。
3. 已有网络继续使用原身份、密钥、日志和数据；不得重新 bootstrap、手工改 Head/ACL/registry，
   不得为通过验收建立另一套空网络。必要迁移必须验证旧 authority，并由正常事务留下可重验结果。
4. 在实现前核对真实部署依赖：本地软件 CA 的持久密钥、证书链、不可变封装与授权接管、
   executor/fencing、服务证书和客户端本地密钥接口。当前不要求 KMS/HSM；其强化方案仅见
   [后续扩展计划](kms-hsm-hardening-plan.md)，不得再以缺少该服务、硬件或配置阻塞上线。
   测试密钥、假 availability hash、fixture 配置或仅有 `crypto.Signer` 接口都不能算作生产接通；
   接口本身也不保证密钥不可导出。实际缺项须具体说明并继续处理，不能到交付时才揭示。

## 沿一条真实业务链路实现

- 从管理员正常创建 Device/邀请的入口开始，进入实际私有控制服务，完成鉴权、expected head/request
  binding、状态机重算、Raft durable commit、提交后 QC 和持久投影。`control_ping` 只能验证其自身。
- 邀请必须生成客户端真正可用的交付物；静态 distribution、catalog 验签、HY2 bootstrap/独立 TCP
  fallback、受限 capability、内层 Enrollment TLS 必须使用正式服务。公网 Nginx 不承接动态 claim。
- 将 reservation、provisional issuance、approval、completion 接入同一 daemon 和共享的认证状态，
  使用真实证书、密钥封装、制品存储与配置渲染。不能注入固定结果、空配置或另一套 head 伪装接通。
- 客户端经正常流程完成身份保存、私有 config 获取和实际激活，再提交有效签名报告；由控制面持久结果
  和界面回读确认。端口可达、页面可打开、拒绝未签名请求、证书通过均不代替业务成功。
- 动态 ControlSet 必须有正常晋升/移除入口，接入 learner catch-up、joint/final、实际副本独立重算与
  quorum。组件故障注入不能冒充已部署的多成员运行；少数副本不能完成安全关键写入。
- 按本次变更验证重试、进程重启与中断恢复；同一事务返回原结果，不能重复消费邀请或重新签发身份。
  确认临时隧道、服务身份隔离与 token/intent 隐私，不能通过弱化校验来打通流程。

## 部署、替换和交付

1. 运行改动所需测试及仓库规定的检查，提交可复核实现。用户已授权上线时继续执行 `CLAUDE.md`
   的精确提交、单次构建、release/publish、SSH/SCP 原子激活流程；旧提示词的“不部署”不撤销当前授权。
2. 通过受验证迁移使当前在用设备接续新版；随新版接管删除旧入口、handler、反代、启动项、配置、
   客户端回退及失效文案/测试。Gate B/M7 用于核对实际替换，不是继续保留旧功能的授权。
   不为当前未部署的平台无限保留旧路径，不把既有数据和历史证明的保留等同于旧服务仍可运行。
3. 核对实际激活制品与生效配置，从正常入口做本次改动相关的生产验收，回读业务结果及认证证据；
   同时检查旧引用与旧路由已退出。不要把部署脚本、模板、包级测试或手工拼接报文当作生产流程。
4. 报告精确提交、实际部署范围、正常流程证据、删除内容和剩余缺口。真实部署细节只写忽略的
   `docs/status/`，更新 `current.md` 的当前事实。确有外部阻碍时写明具体条件，不能报“完成”。

当前控制面迁移以用户指定的 #7/#8/#9 及其新版替换为范围；DNS 生命周期按独立 issue 的边界处理。
不扩改 Windows 客户端；未部署 Windows 不阻塞现网迁移，Android 蜂窝专项和 Linux arm64 实机不
替代也不阻塞本次所需验收。客户端不得恢复完整路径扫描、重复探测或启动等待。

交接须写出下一处具体接线/迁移工作、已运行的检查和未部署项。接手者继续执行，不能再次把
“还有 daemon、客户端或部署待接入”作为一项核心功能已完成后的普通后续事项。
