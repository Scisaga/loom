**日期** 2026-08-23 · **状态** 生效

`loom status` 的"全网快照分布"只统计了**直接拉到**的那几台。够不到的节点
靠转述进来(§16.1.2),它们的 `applied` 就在观测里,却从没被算进去。

实测:5 台机器的表上只列了 3 台。access-a 跟 cn-a、cn-b 没有隧道,于是这两台
在这张表上**根本不存在**。

危险的不是少两行,是**少得静默**:落后的那台如果恰好直接够不到,你看到的
是一张"全网一致"的表。这张表存在的唯一理由就是发现不一致。

Web 界面没有这个 bug —— 它遍历的是含转述节点的 `View.Nodes`。**同一件事
算了两遍,只有一遍是对的**,和 D51 那次 `pinnedDecls` 重复推导同一个毛病。
