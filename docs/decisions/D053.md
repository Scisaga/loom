**日期** 2026-08-23 · **状态** 方向已定,待实现

实测 mtr 证明了一件端到端测量永远看不见的事:

```
cn-a → edge-b:  192.0.2.30 → 192.0.2.31 → 198.51.100.30 → 203.0.113.30
cn-b → edge-b:  192.0.2.32 → 192.0.2.33  → 198.51.100.30 → 203.0.113.30
                                                └────── 完全相同 ──────┘
```

**cn-a 和 cn-b 到柏林,从第三跳起是同一条路。** 这解释了为什么两条候选的
实测值几乎一样(646ms / 600ms),也意味着**在它们之间切换是徒劳的** ——
共用段拥塞时两条一起坏。

还有一件事只有逐跳才看得见:代价全在出境那一跳(4ms → 203ms)。所以
**对境外目标,选哪台国内中继几乎无所谓**。

**先只做记录与展示**,不接进选路:

- 每个节点的上报者定期 mtr **自己那几段**(只有起点看得见那条路)
- 跳表转述出去,中控台可查
- IP → ASN 用**离线**数据表。不接在线服务 —— 那会把拓扑告诉第三方,
  也给系统加一个外部依赖

频率:一次 mtr 约 45 个包、30 秒,且 ICMP 常被限速。**几小时一次**,
不是几分钟一次。
