## 页面分工

| Tab | 用户任务 | 内容与操作 |
|---|---|---|
| 连接 | 开始连接，选择上网方式 | 顶部配置入口；当前查看配置的 VPN 状态与主操作；Direct / Auto / 指定出口；页内出口列表；进入路由页。未加入时提供前往设置的入口 |
| 路由 | 看流量经过哪里，查网络状态 | 按相同实际链分组的当前路径；逐项候选、分段证据、原因与时间；DNS / HTTPS、可信上报与服务器观测 |
| 设置 | 管理连接配置与设备 | 配置列表、新增、重命名、删除；扫码或导入邀请；所选配置的状态与更新；连接通知；组件与本机密钥信息；仅 Debug 可见的 Direct fixture |

三个 Tab 保留独立滚动位置，底部导航固定。连接页保留单一 VPN 主操作；详情、入网信息和
本机组件不堆在日常操作之间。路径与网络状态是只读展示，不增加路径编辑或重新探测按钮。

## 多配置

与 Windows 保持同样的基本语义：可以保存多份连接配置，每次只运行一份。Android 的单一
`VpnService` 限制活动 VPN 数量，不限制应用保存的配置数量。

- 顶部配置入口定位到设置页的配置列表。选择条目只改变正在查看的配置，不自动连接；三个 Tab
  共享当前查看对象，模式、更新、重命名和删除始终绑定该对象。
- 列表独立标出“当前查看”和“已连接”。查看另一份未连接配置时，连接页单独显示实际承载
  流量的配置，并提供“切换并连接”；路径页不显示另一配置的路径或观测。
- 切换连接先停止旧宿主、调度和数据面，再启动新配置；期间禁用重复操作。启动失败显示真实
  错误，不把旧状态标成新配置已连接，也不自动把另一份身份启动起来。
- 每份配置独立保存加入身份、可信配置、证书与秘密、模式/出口偏好、待加入事务、防回退
  floor 和 v2 latch。设备被停用的状态只作用于该身份，不能通过本地改名或导入绕过。
- 底层网络代的入口 probe registry 继续在设备层共享；切换配置不会产生新网络代，也不会追加
  全路径探测。与配置相关的候选、签名观测与路径展示仍保持身份隔离。
- 新增采用页内“名称 → 扫码或导入邀请 → 加入并保存”。提交前取消不留下空条目；已开始的
  加入事务保留原身份和恢复信息。加入成功的新配置保持未连接，不干扰正在运行的配置。
- 重命名只修改本机显示名称。删除仅针对当前选中的未连接配置，并在卡片内确认；运行中的配置
  先断开。删除本机配置不撤销中控 Device，不影响其他配置。

## 状态与交互

| 状态 / 操作 | 界面反馈 |
|---|---|
| 首次使用 | 连接和模式选择禁用；“前往设置加入网络”定位到加入页；扫码、文件导入为两个明确入口 |
| 加入成功 | 设置显示已加入与配置状态；连接页可以连接，加入成功本身不自动启动 VPN |
| 未连接 / 路径未知 | 路由页显示“连接后显示各服务的实际路径”或“当前路径尚未确认”，不沿用旧连接路径 |
| 连接中 / 断开中 | 主操作沿用宿主生命周期状态，断开中禁用；系统始终开启 VPN 时说明由系统管理 |
| 连接失败 | 显示真实失败原因并提供再次连接；不把未知观测标绿 |
| 选择出口 | 在连接模式卡片内展开已授权出口；选择前仍显示已确认模式；取消保持原偏好；Direct / Auto 收起列表 |
| 出口应用中 / 失败 | 应用中禁用重复提交；最终模式来自宿主状态，失败保留已确认偏好及错误信息 |
| 当前路径 | 默认最多两组摘要；详情在同一卡片内一次展示一项，以“上一项 / 收起 / 下一项”浏览 |
| 证据未知 | 缺失数据保持 `—` 或未知；详情保留协议、来源、原测量时间、原因与决策时间，不合成整条路径质量 |
| 待加入事务 | 重试、放弃与二次确认都留在设置页；放弃只执行原有待加入事务语义 |
| 设备已停用 | 展示终止原因，连接及 Debug Direct 保持禁用，不通过重新导入绕过终止状态 |

## 按钮与窄屏

- 页面左右留白 22 dp，卡片内边距 16 dp；连接模式默认三列，列间距 8 dp。
- 按钮文字沿用 Material `labelLarge`；水平内边距 10 dp，最小触摸高度 48 dp。
- 用当前字号测量三个标签的最大宽度，加上内边距后计算三列所需空间。
- 放不下时整组纵排、每个按钮占满可用宽度。文字保持完整单行，不缩小、不裁掉“指定出口”。
- `320 / 360 / 430 dp` 与放大字体共同复核；大字体允许页面纵向滚动，导航始终可达。

## 维护与实现

SVG 由共享绘图脚本生成，复用仓库完整版品牌图形。修改脚本后重新生成并人工检查渲染结果：

```bash
python3 scripts/generate_android_client_prototypes.py
```

**实现边界：** 本轮原生源码已调整三页职责与三态按钮布局；Android 当前存储仍为单份身份与
配置。图中的多配置列表、新增、重命名、删除及跨身份切换是待实现设计，不能作为已支持功能。
落地时还需增加配置索引与身份隔离，并原位复用现有单配置数据，不能重新生成已有身份。

原生入口位于 [MainActivity.kt](../../../clients/android/app/src/main/java/io/github/scisaga/loom/MainActivity.kt)。
真实数据与客户端选路边界遵循 [design.md §7.3](../../../docs/design.md#73-v1-只有一个逻辑日常入口)。
原型与编译结果不代表手机已更新；实际安装状态只记录在忽略的 `docs/status/current.md`。
