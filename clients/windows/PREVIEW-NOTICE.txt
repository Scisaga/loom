Loom Windows client development preview

Portable Mixed has passed the native Windows QR/DPAPI/signed-pull/Mixed test.
Portable Mixed, Portable TUN, and Installed include the native first-launch and Connection GUI.
Portable TUN has not completed real adapter, route, and cleanup validation.
Installed interactive mode currently requires elevation and uses ProgramData plus
machine-scope DPAPI directly. It does not yet include MSI, ProgramData ACL setup,
an ordinary-user tray process, or restricted Service IPC.

The Loom executable and this checksum set are not Authenticode-signed release
artifacts. Do not register the unpacked Installed executable as a LocalSystem
service. Use Portable Mixed for current local development tests.
